MioAmp

A customizable local audio player for macOS 14 or later.

Choose who can use this app

  • Install for me only: installs in your home folder’s Applications folder, without administrator authorization.
  • Install for all users of this computer: installs in /Applications and requires administrator authorization.

If the destination screen is skipped, click Change Install Location… on the Installation Type screen.

This installer contains no privileged setup scripts. Installing for yourself does not remove an existing shared installation.
