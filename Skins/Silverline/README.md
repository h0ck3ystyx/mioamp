# Silverline

A classic desktop-audio skin for MioAmp, inspired by the supplied silver-and-blue player reference. Original vector artwork: steel chassis, bright metallic bevels, cobalt display fields, monospaced track text, and five round silver transport buttons. No reference-image pixels or third-party branding are included.

Import `skin-packages/Silverline.mioampskin` through **Skins > Import Skin…**, then choose **Install & Apply**. No app rebuild is needed. The package contains `manifest.json` at its root and six SVG assets under `art/`.

The current v1 skin format preserves MioAmp's layouts, native sliders, window titles, and system selection styling. A darker steel chassis keeps the shared light text roles readable; a fully bright silver chassis with independently colored display/control text would require more semantic color roles in the renderer.

Validated October 3, 2026 by importing and applying the package through the running app. Visually checked player, equalizer, and playlist. Local preview captures live beside the package; these show the user's existing queue and are not App Store assets. No playback, queue, EQ, or volume changes were made during verification.
